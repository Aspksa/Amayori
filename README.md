# Amayori

Проект для Windows с облачной языковой моделью Cloud.ru и собственной долговременной памятью.

## Запуск

1. Установите Node.js LTS версии 22 или новее.
2. Распакуйте репозиторий в отдельную папку.
3. Запустите `Amayori.bat` двойным щелчком.
4. Скрипт запускает сервер, ждёт ответа `/api/health` и автоматически открывает `http://127.0.0.1:57474/`.

Docker не нужен. При первом запуске BAT проверяет пакеты `pg` и `three` и автоматически выполняет `npm.cmd ci`, если они отсутствуют. Для первой установки нужен интернет; повторный запуск с установленными пакетами не требует npm. Лог: `logs/start.log`.

Graphiti и CrewAI пока не подключены — это начальная оболочка проекта.

## Плавающий чат-аватар

Круглый аватар можно перетаскивать мышью или пальцем по экрану. Позиция сохраняется в браузере. Короткое нажатие открывает и закрывает окно чата. Крестик закрывает окно. Пока это интерфейс-заготовка: сообщения отображаются локально, модель ИИ и сохранение истории на сервере не подключены.

## Версия 0.2.0

- Cloud.ru: укажите API-ключ, ID модели и HTTPS endpoint в разделе «Подключения и настройки», затем нажмите «Проверить связь».
- Аватар открывает настоящий чат через серверный API `/api/chat`. Ключ не раскрывается браузеру.
- Локальный архив `data/chats.json` и базовый граф совместного появления слов `data/graph.json`; API `/api/memory/status`, `/api/graph`.
- Graphiti пока не интегрирована: локальная память и граф — самостоятельная базовая реализация, а не её полноценный движок.
- Нет потоковой генерации и автоматической загрузки списка моделей; ID модели указывается вручную.
- Ключ хранится в `data/cloudru-settings.json`. Не публикуйте папку `data`, делайте резервные копии самостоятельно.
- Проверка кода: `npm.cmd test`. Используются Node.js и зависимости из `package-lock.json`.

## Разработка 0.3.0

Добавлена интерактивная карта базового графа (Canvas: масштабирование колесом, перемещение полотна и узлов). Это не Graphiti: сущности пока представлены словами.


Graphiti требует отдельного интеграционного слоя, настройки хранилища и тестирования. Наличие исходников само по себе не означает работающую интеграцию.

## Проверки перед слиянием

`npm.cmd test` запускает модульные и HTTP smoke-тесты, включая проверку того, что API настроек не возвращает секрет. CI выполняется через Node checks. Полный Windows-прогон, реальные Cloud.ru запросы и интеграция Graphiti требуют отдельной проверки; не считать их завершёнными только по успешному CI.

## Опциональный локальный мост Graphiti

В сервере реализована точка подключения к отдельному локальному HTTP-адаптеру через переменную окружения `AMAYORI_GRAPHITI_BRIDGE_URL`. По умолчанию она отключена. Проверка состояния: `GET /api/integrations/status`.

Контракт Graphiti-адаптера: `POST /ingest` с JSON `{"user":"...","assistant":"..."}`. Адрес должен быть локальным HTTP URL, например `http://127.0.0.1:8765/`. Мост только принимает переписку и на подбор контекста для ответа не влияет. При недоступности адаптера чат продолжает работать с локальным архивом. **Это только интерфейс интеграции, не реализация сервера Graphiti.** Не подключайте недоверенные локальные службы: им передаётся содержимое переписки.

## Cloud.ru — улучшенный выбор модели и чат

1. В разделе «Подключения и настройки» вставьте API-ключ, введите ID модели и сохраните.
2. Нажмите «Загрузить доступные модели»: Amayori запрашивает список по `/v1/models` через локальный сервер. Если ваш тариф или API не поддерживает этот метод, можно указать ID вручную.
3. Нажмите «Проверить связь», чтобы отправить короткий тестовый запрос (может расходовать лимит).
4. Откройте плавающий чат. В его заголовке можно выбрать другую модель для конкретного сообщения, не меняя модель по умолчанию.
5. Последние 100 сообщений подгружаются из локального архива после перезагрузки страницы.

Ключ никогда не включается в ответ `GET /api/settings`. API ошибок Cloud.ru не возвращает сырые тела HTTP-ответов, чтобы случайно не раскрыть конфиденциальные сведения. Список моделей зависит от фактической поддержки Cloud.ru; автоматическое обнаружение не гарантируется.

## Развитие чата 0.4.1

Добавлены полноэкранный режим, поиск по отображённой истории, экспорт последних 100 архивных сообщений в TXT и очистка экрана без удаления архива. Поиск не охватывает сообщения вне загруженной истории; экспорт содержит личные сообщения и должен храниться безопасно.

## Подключение Cloud.ru без ручного URL

Адрес сервиса Foundation Models установлен внутри сервера. Пользователю достаточно ввести API-ключ и нажать «Загрузить доступные модели»: ключ сохранится локально, затем сервер запросит `GET /v1/models`. Названия берутся из `metadata.name` официального API Cloud.ru. Если список не загрузился, приложение показывает причину (например, 401 — ключ не принят, 403 — нет доступа) и позволяет ввести ID вручную. Для проверки отправки сообщений нажмите «Проверить связь».

Соединение с облачным API **по-прежнему защищено HTTPS**; убрано только поле URL из интерфейса, а не шифрование.

## Project Golem — визуализация памяти

Добавлен раздел «3D-мозг» с вращением, масштабированием и подсветкой результатов поиска. Amayori формирует данные из локального `data/graph.json` в совместимом с Golem формате `{title,cat,col,pos}`. API: `GET /api/golem/cortex`, `POST /api/golem/query`.

**Ограничение:** текущая реализация — собственный встроенный просмотрщик на Canvas с детерминированным размещением узлов и поиском по словам. Она **не включает** оригинальные Python/Flask, LanceDB, Gemma, UMAP или Three.js из CyberMagician/Project_Golem. Для настоящей семантической 3D-карты нужно отдельно интегрировать исходный движок и эмбеддинги. Исходный проект: https://github.com/CyberMagician/Project_Golem.

### Построение настоящей семантической карты Golem

В Windows запустите `Amayori.bat build-brain` (нужен установленный Python и интернет для первой загрузки модели). Скрипт создаёт локальные эмбеддинги и UMAP/PCA-проекцию узлов `data/graph.json` в `data/golem/`. После обновления страницы «3D-мозг» показывает семантические координаты. Docker не нужен. При отсутствии Python/эмбеддингов работает прежняя обзорная карта. **Важно:** подсветка поиска пока лексическая, а не по косинусной близости. Веб-визуализация реализована на Canvas, не на Three.js. Первоначальная загрузка модели и расчёт UMAP могут быть ресурсоёмкими.

### Семантический поиск (экспериментальная утилита)

Добавлен `integrations/golem/search.py`: скрипт читает запрос из стандартного ввода, использует ту же модель эмбеддингов, что и построитель, вычисляет косинусную близость к `golem_vectors.npy` и возвращает индексы наиболее близких узлов в JSON. Пока это **отдельная утилита**; маршрут `/api/golem/query` продолжает использовать поиск по словам. Для автоматической интеграции в интерфейс требуется безопасный управляемый Python-процесс и проверка зависимостей.

## Автоматическое построение Project Golem

При обычном запуске `Amayori.bat` сервер автоматически проверяет изменения архива `data/chats.json` и, если переписки появились или обновились, в фоновом режиме строит семантический мозг. Проверка повторяется примерно раз в минуту. При первом построении установленный Python 3 автоматически загружает необходимые Python-пакеты и модель эмбеддингов (нужны интернет, свободное место и время). Чат и веб-интерфейс при этом продолжают работать. Если Python отсутствует, показывается предварительная карта; подробности ошибок записываются в `logs/start.log`. Для ручного повторного построения по-прежнему доступна команда `Amayori.bat build-brain`. Отключение автоматического построения: переменная окружения `AMAYORI_GOLEM_AUTO_BUILD=0`. Для запуска требуется установленный Python 3 с доступным `py` (Windows) или `python3`.


## Исправления 0.6.1

- Удалён дублирующий модуль `core/cloud.mjs`: он не использовался сервером и возвращал сырое тело HTTP-ответа Cloud.ru в тексте ошибки. Рабочим остаётся `core/cloud-client.mjs`, который подставляет понятные сообщения по кодам 400/401/403/404/429/500/503.

- `POST /api/knowledge/facts` и `POST /api/feedback` без PostgreSQL отвечают 409 с понятным текстом вместо 500.
- Размерность векторов 384 задаётся одной константой `EMBEDDING_DIMENSIONS`, а не повторяется в пяти местах.
- Убраны неиспользуемые импорты в `server.mjs` и дублирующаяся проверка в CI.
- `docs/amayori-roadmap.json` приведён в соответствие с действительностью: открытых PR нет, PR 21, 22, 23, 25 давно слиты, локальный inference удалён в PR #27.

## Удаление MemOS 0.6.2

MemOS полностью удалён из проекта: переменная окружения `AMAYORI_MEMOS_BRIDGE_URL`, функции `memosSearch` и `memosStore`, участие моста в сборке контекста чата (добавленное в 0.6.1), поле `memos` в `GET /api/integrations/status`, поле `memosConnected` в `GET /api/memory/status`, а также все упоминания в документации и тестах. Настраивать и устанавливать MemOS не требуется.

Долговременная память работает без него: локальный архив, канонический PostgreSQL, факты, векторный поиск pgvector и подбор эпизодов по словам не затронуты. Опциональный мост Graphiti сохранён отдельно и по умолчанию отключён.

## Языковая модель

Для генерации ответов используется только Cloud.ru. Локальные языковые модели, llama.cpp, Ollama и переключение на локальный inference не поддерживаются. PostgreSQL, pgvector, архив чатов и граф знаний сохраняются как независимые компоненты памяти. Экспорт вручную проверенных обучающих примеров не запускает обучение и не требует локальной модели.


## Исправления запуска, отдельного Голема и памяти чата

- Голем открывается только по ссылке на отдельную страницу `/golem`. На главной остаётся обычная 2D-карта знаний; встроенный WebGL-модуль удалён из её загрузки.
- Отдельная страница показывает резервную карту до первого успешно отрисованного 3D-кадра. При потере WebGL-контекста, ошибке отрисовки или отсутствии кадров более шести секунд резервная карта возвращается автоматически. После восстановления 3D включается только после нового успешного кадра.
- Настройки автовращения и размера узлов применяются и к 3D, и к резервной карте. Открытая страница проверяет изменения настроек каждые 12 секунд.
- Чат использует семантический поиск pgvector, если заданы `AMAYORI_DATABASE_URL` и `AMAYORI_EMBEDDING_MODEL` и архив уже проиндексирован. Размерность модели должна соответствовать существующей схеме: 384. Учитываются до четырёх результатов с косинусным расстоянием не более 0.5; дубликаты убираются, размер контекста ограничен.
- При недоступности векторного поиска чат сохраняет поиск эпизодов по словам и подбор фактов. Без настройки базы продолжает работать локальный архив.
- Наличие программной поддержки PostgreSQL не означает, что сервер базы и pgvector уже установлены на компьютере. Реальные Cloud.ru-запросы требуют действующего ключа и доступной модели эмбеддингов.

## Интерфейс 0.6 — Обсидиан и золото

Переработан весь рабочий интерфейс: узкая панель SVG-значков, отдельные экраны диалога, памяти, карты и настроек. Общая длинная страница заменена переключением разделов. Голем по-прежнему открывается отдельно.

Чат стал основным большим рабочим экраном. На других экранах аватар открывает тот же диалог: черновик и история сохраняются при переходах. Добавлены растущее поле ввода, безопасное оформление кода, копирование ответов, подсветка поиска и блокировка повторной отправки. На сенсорных устройствах Enter переносит строку.

Архив, факты и проверка памяти разделены. Вместо технического JSON отображаются понятные карточки. Активный раздел, состояния подключения и доступность действий отмечаются автоматически. Плотность, подписи меню и анимации настраиваются отдельно.

Описание палитры, поведения и проверок: [docs/interface-design.md](docs/interface-design.md). Браузерные проверки: `npm.cmd run test:ui` после установки зависимостей разработки и Chromium. Обычный BAT не устанавливает инструменты разработки.
