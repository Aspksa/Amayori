# Amayori × Project Golem — единое большое обновление 0.5.0

## Цель
Один согласованный релиз, один PR, одна проверка перед слиянием. Не разбивать на десятки несвязанных выпусков. Golem — **визуализатор семантической памяти**, не система агентов.

## Критерии готовности
- Семантический поиск реально возвращает близкие по смыслу узлы, а не просто совпадения слов.
- UI различает настоящий UMAP/PCA и демонстрационный режим.
- Архив чатов не теряет старые сообщения.
- BAT работает из папки с пробелами и с внешнего диска.
- Без Python приложение продолжает работать.
- Ни один тест не падает, CI завершён успешно.
- Все функции помечены как «готово», «частично» или «не сделано» на основании проверок, не обещаний.

## Текущая реализация
Есть Canvas-просмотрщик 3D-проекции, Python-скрипт построения эмбеддингов/UMAP/PCA, экспериментальный CLI семантического поиска, локальный Node API и резервный лексический поиск. **Этот документ — единое ТЗ на следующий крупный релиз, а не заявление, что все 70 пунктов уже реализованы.**
