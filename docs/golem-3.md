# Golem 3.0
3D-проекция в Canvas без локальных моделей и без установки тяжёлых зависимостей. Кластеры группируются эвристически по первому слову названия (не ML-кластеры). Вращение мышью, масштабирование колесом, переключение 2D/3D, постраничная загрузка, выбор факта и его сохранённого источника.
POST /api/golem/similar принимает {text}, отправляет запрос в Cloud.ru /v1/embeddings через выбранный Cloud.ru endpoint и ищет в pgvector по косинусному расстоянию. Для включения установите AMAYORI_EMBEDDING_MODEL в ID модели Cloud.ru, которая возвращает ровно 384 значения. Доступность такой модели необходимо проверить отдельно. Векторы пока заполняются существующим insertMemory, автоматического индексирования чатов нет.
GET /api/golem/source?id=<numeric> показывает запись факта и source. Для фактов, сохранённых вручную, source='user-confirmed', а не ссылка на сообщение; переход к исходному чату требует отдельной связи source_id. Проекция Canvas 3D не является Three.js WebGL.
