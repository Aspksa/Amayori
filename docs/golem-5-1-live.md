# Голем 5.1 — Живая нейронная сеть
- Виртуализация: PostgreSQL хранит полный граф, WebGL показывает только одну страницу 100/200/300 фактов с переключением областей. Не загружает все данные в память браузера.
- Импульсы: декоративная подсветка узлов при включённой настройке. **Пока не означает реальный поиск воспоминаний**.
- Рост: узлы, впервые появившиеся в текущей области, плавно увеличиваются. Обновление по событию amayori-chat-updated и переключению страниц.
- Исправлена проверка числовых ID и источник сообщений при одновременных запросах.
- Анимация отключается галочками, вкладка в фоне не перерисовывается.
- Ограничение: нет push-уведомлений из PostgreSQL; отображение нового факта требует обновления данных.
