# Голем 5.0 — знания и связи (пункты 1, 4, 6)
1. Извлечение знаний через Cloud.ru: POST /api/knowledge/extract, JSON, text до 4000 символов, необязательный sourceMessageId. Сохраняет до 5 проверяемых фактов.
2. Автоматическое извлечение после чата: включается переменной AMAYORI_AUTO_EXTRACT=1. По умолчанию выключено, чтобы не расходовать API без согласия.
3. Карта связей: GET /api/knowledge/related?id=123 показывает активные факты, связанные общими субъектами или объектами.
4. Противоречия: GET /api/knowledge/conflicts показывает историю замены фактов по паре субъект+отношение. Это история изменений, а не доказательство ложности одного из фактов.
5. Меню и новые элементы управления — на русском. Существующие англоязычные технические имена API оставлены для совместимости.
Ограничения: извлечение моделью может ошибаться; до включения автоматического режима рекомендуется ручная проверка. Для корректного sourceMessageId необходима проверка принадлежности сообщения текущему чату — не передавайте произвольные ID из недоверенного источника.
