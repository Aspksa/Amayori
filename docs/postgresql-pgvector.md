# Единая память Amayori

Единственный источник переписки — `data/chats.json`. Чат, поиск и Project Golem используют этот архив. `data/graph.json` и `data/golem/` являются производными представлениями.

PostgreSQL + pgvector теперь опциональная инфраструктура для будущего поискового индекса. Новые сообщения больше не дублируются в PostgreSQL. Существующие записи базы не удаляются автоматически; проверьте резервную копию перед ручной очисткой. Векторный поиск через PostgreSQL пока не подключён. Статус подключения: `GET /api/database/status`.

## Производный векторный индекс

При установленной переменной `AMAYORI_DATABASE_URL` фоновая сборка Golem после успешного создания локальных эмбеддингов синхронизирует таблицу `amayori_vector_index` с архивом `chats.json`. Индекс не является второй памятью: его можно пересоздать. Удаление сообщений из архива отражается в индексе при следующей успешной сборке. Синхронизация выполняется транзакционно, а ошибка PostgreSQL не блокирует локальный чат.

Для синхронизации требуется Python-драйвер `psycopg` (включён в requirements Golem). Сам PostgreSQL и расширение pgvector устанавливаются отдельно. Старую таблицу `amayori_memories` модуль не удаляет. Поиск чата пока использует локальный индекс Golem; pgvector — подготовленный индекс, не новый источник памяти.
