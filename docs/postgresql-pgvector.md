# Единая память Amayori

Единственный источник переписки — `data/chats.json`. Чат, поиск и Project Golem используют этот архив. `data/graph.json` и `data/golem/` являются производными представлениями.

PostgreSQL + pgvector теперь опциональная инфраструктура для будущего поискового индекса. Новые сообщения больше не дублируются в PostgreSQL. Существующие записи базы не удаляются автоматически; проверьте резервную копию перед ручной очисткой. Векторный поиск через PostgreSQL пока не подключён. Статус подключения: `GET /api/database/status`.
