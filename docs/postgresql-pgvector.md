# PostgreSQL + pgvector (опционально)

Amayori продолжает работать без Docker и без PostgreSQL: локальный архив `data/chats.json` остаётся основным источником для Project Golem.

Для подключения установите PostgreSQL и расширение pgvector на свой компьютер или сервер, создайте отдельную базу и пользователя с правом `CREATE` в базе (для установки расширения могут потребоваться дополнительные права администратора). Установите зависимости командой `npm.cmd install` в папке проекта.

Перед запуском задайте переменную окружения `AMAYORI_DATABASE_URL` со строкой подключения, например `postgresql://amayori:YOUR_PASSWORD@127.0.0.1:5432/amayori`. Не сохраняйте настоящий пароль в GitHub, BAT или файлах проекта. Для подключения к удалённой БД с проверкой сертификата установите `AMAYORI_PG_SSL=1` и настройте доверенные CA.

При запуске сервер создаёт расширение `vector` и таблицу `amayori_memories`, затем зеркалирует новые сообщения в PostgreSQL. Состояние соединения доступно по `GET /api/database/status`. Если БД отключена или временно недоступна, локальный чат продолжает работать; пропущенные записи пока не синхронизируются автоматически. **Важно:** поле `embedding vector(384)` и функция векторного поиска подготовлены, но автоматическое вычисление эмбеддингов и подключение pgvector к поиску по чату пока не реализованы. В текущем состоянии новые записи имеют `embedding=NULL` и семантический поиск по ним через PostgreSQL ничего не вернёт. Project Golem продолжает использовать существующий локальный механизм.
