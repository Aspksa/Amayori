# Собственный мозг Amayori: Cloud.ru сейчас, локальная модель позже

Ядро чата и память не зависят от выбранной модели. По умолчанию ответы создаёт Cloud.ru. Для локальной модели, предоставляющей совместимый OpenAI Chat Completions API, установите переменные окружения перед запуском:

```powershell
$env:AMAYORI_MODEL_PROVIDER = 'local'
$env:AMAYORI_LOCAL_MODEL = 'your-installed-model-id'
$env:AMAYORI_LOCAL_ENDPOINT = 'http://127.0.0.1:11434/v1/chat/completions'
.\Amayori.bat
```

Указанный адрес — пример для Ollama с совместимым API. Сначала установите и запустите локальный сервер модели отдельно. Для возврата к Cloud.ru удалите `AMAYORI_MODEL_PROVIDER` или установите `cloud`. Текущий режим доступен по `GET /api/brain/model`. Пароли, токены и данные чата не отправляются на произвольные внешние адреса: локальный режим разрешает только loopback.

**Не реализовано в этом PR:** обучение весов, LoRA, автоматическая установка моделей, автоматическая смена провайдера и контроль качества дообучения. Модель и память — разные компоненты; смена модели не стирает память. Для обучения потребуются датасет из проверенных примеров, лицензированная открытая модель, тесты качества и отдельный тренировочный процесс.
