# Память и знания

Актуальное описание карточек, извлечения, объединения повторов, противоречий и тематических связей: [Знания 0.11](knowledge.md).

Без PostgreSQL знания сохраняются локально. При подключённой базе она остаётся каноническим хранилищем чатов и карточек; переключения на локальные данные при ошибке базы нет. Неактуальные версии сохраняются для истории, а выбранные актуальные факты участвуют в контексте ответов.

Обратная связь и экспорт проверенных примеров не изменяют веса языковой модели. MemOS не требуется.
