# Memory Evolution 1.0 — базовая инфраструктура
PostgreSQL остаётся каноническим архивом чатов. pgvector остаётся индексом векторного поиска, но для наполнения embeddings требуется отдельный поставщик векторов: автоматическая семантическая индексация пока не включена.

Новые API: GET /api/knowledge/facts?q=, POST /api/knowledge/facts с JSON {subject,predicate,object}, GET /api/knowledge/graph, POST /api/feedback с JSON {chatExcerpt,rating:1|-1,note}, GET /api/feedback/stats.

Факты вводятся явно, без автоматической записи догадок модели. Изменения одного отношения сохраняют прежнюю версию как superseded; старые факты не стираются. Обратная связь фиксируется для анализа качества, но не изменяет веса модели. Для использования функций требуется AMAYORI_DATABASE_URL. Интерфейс управления фактами, автоматическое извлечение Cloud.ru и полноценный графический редактор — следующие этапы.
