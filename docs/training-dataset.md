# Подготовка данных для будущего обучения Amayori

Этот модуль **не обучает нейросеть**. Он экспортирует только вручную проверенные примеры в JSONL, совместимый с форматом диалогов. Автоматический сбор всех переписок запрещён.

Создайте локальный файл `reviewed.json` (не добавляйте его в GitHub):

```json
[
  {"approved": true, "instruction": "Привет", "response": "Здравствуйте!"}
]
```

Затем выполните:

```powershell
node scripts/export-reviewed-dataset.mjs reviewed.json training.jsonl
```

Команда отклоняет неутверждённые и пустые примеры, слишком длинные записи и некоторые распространённые формы секретов. Проверка секретов не исчерпывающая: **перед экспортом вручную удалите личные сведения, ключи, пароли и материалы без разрешения на обучение**. Выходной файл не перезаписывается автоматически. Не публикуйте датасеты в репозитории.

Следующие задачи: версии датасетов, раздельные train/eval выборки, LoRA/QLoRA, измерение качества и откат адаптера. До этого обучение модели не реализовано.
