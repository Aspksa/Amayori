# Голем 6.0
Реализованы трассы использованных структурированных фактов, поиск общих сущностей (предложения мостов), отчёт иммунитета, адаптивный WebGL и адаптивная вёрстка. Нейронный след показывает факты, переданные в контекст ответа, но не внутреннее рассуждение модели. Мосты не подтверждаются автоматически. Для отчётов необходим PostgreSQL. Не реализовано: оценка возраста знаний, семантические межпроектные мосты, GPU-бенчмарки и полноценный 4K визуальный тест.
