# Интерфейс Amayori 0.6

## Визуальная система

| Назначение              | Значение  |
| ----------------------- | --------- |
| Основной фон            | `#0c0d10` |
| Поверхность             | `#121317` |
| Приподнятая поверхность | `#191a1f` |
| Граница                 | `#28292f` |
| Основной текст          | `#ebe8e2` |
| Вторичный текст         | `#9999a4` |
| Золотой акцент          | `#d6b775` |

Системные шрифты, локальные SVG-значки, без внешних шрифтов и CDN. Золото обозначает активный раздел, основное действие и выбранные знания. Цвет не является единственным признаком состояния: используются подписи, `aria-current`, `aria-selected` и доступные названия кнопок.

## Навигация

Узкая левая панель: 72 px на компьютере и 52 px на телефоне. Подписи можно включить на широком экране. Вместо одной длинной страницы показывается один раздел; прокрутка остаётся внутри истории, архива или группы настроек. Идентификаторы контейнеров не совпадают с маршрутами, поэтому фрагменты URL не сдвигают шапку.

- `#chat` — рабочий экран диалога.
- `#memory/archive`, `#memory/facts`, `#memory/quality` — история, знания и читаемые отчёты.
- `#graph` — обычная карта знаний с поиском и инспектором.
- `#settings/connection`, `#settings/appearance`, `#settings/brain` — отдельные группы настроек.
- `/golem` — самостоятельное окно. В основной интерфейс 3D-просмотрщик не встраивается.

Работают прямые ссылки, кнопки назад/вперёд, клавиатура вкладок и `Ctrl+K` / `Cmd+K` для поиска в архиве.

## Один диалог

Один экземпляр компонента перемещается между рабочим экраном и плавающим окном. История и черновик при переходах не копируются и не сбрасываются. На экране диалога аватар скрыт как лишняя кнопка открытия; в остальных разделах он открывает тот же чат. Положение аватара сохраняется в браузере, правое нажатие открывает его настройки.

Поле ввода растёт по мере набора. На компьютере Enter отправляет сообщение, Shift+Enter добавляет строку; на сенсорном устройстве Enter добавляет строку, отправка выполняется отдельной кнопкой. Повторное отправление во время запроса блокируется. Код, выделение и результаты поиска создаются безопасными DOM-элементами, без вставки HTML модели. Есть копирование ответа и кода.

Поиск в чате, поиск в архиве и экспорт ограничены последними 100 сообщениями, которые предоставляет существующий API. «Очистить экран» не удаляет архив. Сообщения модели и списки моделей не дублируются. При отсутствии подключения показывается явное состояние.

## Состояния и настройки

«Модель выбрана» не означает проверенное соединение. Статус «Подключено» появляется после успешного тестового запроса или ответа чата. Значения счётчиков поступают из API; пустая карта не подменяется демонстрационной сетью в основном интерфейсе.

Индексация и поиск по смыслу доступны в интерфейсе при настроенных PostgreSQL и модели эмбеддингов. Неиспользуемые старые WebGL-скрипты и дублирующиеся обработчики удалены. Голем и его резервная карта используют ту же чёрно-золотую палитру.

Ключ Cloud.ru хранится сервером локально. Чтение настроек не возвращает ключ. После сохранения введённый ключ очищается из поля. В браузере сохраняются только внешний вид и положение аватара. Системное уменьшение движения имеет приоритет над анимациями интерфейса.

## Проверки

`npm test` — модульные проверки и HTTP smoke-тесты.

`npm run test:ui` — Chromium: маршруты, формы, отсутствие дублей, защита от HTML в сообщениях, черновик, поиск, экспорт, сенсорный ввод, отдельный Голем и восстановление после потери WebGL. Проверяется весь интерфейс на ширинах 320, 390, 768, 1366, 1440 и 1920 px.

Браузерная проверка запускает изолированную временную копию без пользовательского архива, ключей и подключённой базы. Запросы модели подменяются тестовыми ответами и не расходуют лимит Cloud.ru. Для локальной разработки: `npm.cmd ci`, `npx.cmd playwright install chromium --only-shell`, `npm.cmd run test:ui`.

BAT устанавливает только рабочие зависимости (`--omit=dev`); инструменты браузерной проверки для обычного запуска не нужны. В CI Node-проверки выполняются в Windows и Linux, Chromium — в Linux.
